# QuizApp — Интерактивный Квиз-Портал в Реальном Времени

**QuizApp** — это современное Full-Stack веб-приложение для создания и проведения многопользовательских викторин (квизов) в режиме реального времени, разработанное специально в качестве проектной задачи для **ВК**.

Приложение спроектировано по принципу универсального личного кабинета (Unified Account), где каждый зарегистрированный пользователь может мгновенно переключаться между ролью Ведущего (создавать и запускать игры) и ролью Игрока (подключаться по PIN-коду к активным лобби).

---

## Технологический Стек

- **Frontend:** React.js, HTML5, CSS3 (Flexbox/Grid), `socket.io-client` для real-time связи.
- **Backend:** Node.js, Express.js, `socket.io` для WebSocket сервера.
- **База данных и ORM:** SQLite, Prisma ORM (v7) с высокопроизводительным адаптером `@prisma/adapter-better-sqlite3`.
- **Безопасность:** Хеширование паролей (`bcryptjs`), защита сессий токенами авторизации JWT (`jsonwebtoken`).

---

## Ключевые Фичи и Отказоустойчивость

1.  **Синхронный Мультиплеер (Socket.IO):** Мгновенная передача вопросов, синхронизация таймеров раунда и сбор ответов игроков в реальном времени.
2.  **Защита от вылетов и переподключение (Reconnection):** Если игрок обновил страницу или потерял связь во время матча, при повторном вводе ПИН-кода сервер бесшовно восстановит его сессию и сохранит все ранее заработанные звезды!
3.  **Вход в запущенную игру (In-game Join):** Новые участники могут заходить в комнату прямо посреди активного матча и сразу подключаться к текущему раунду.
4.  **Глобальная история и Топ победителей:** Все сыгранные игры сохраняются в БД. На главном экране выводится интерактивная история матчей (клик по карточке открывает полноэкранные результаты игры) и таблица чемпионов платформы.
5.  **Защита от читерства:** На экраны игроков сокет-сервер отправляет варианты ответов без меток правильности. Ведущий во время таймера видит правильный ответ благодаря скрытому индикатору.

## Инструкция по локальному запуску

Для работы приложения на компьютере должен быть установлен **Node.js** (v18+).

### 1. Запуск серверной части (Backend)

```bash
# Перейдите в папку бэкенда
cd backend

# Установите зависимости
npm install

# Примените миграции базы данных Prisma
npx prisma migrate dev --name init

# Сгенерируйте клиент Prisma
npx prisma generate

# Запустите сервер в режиме разработки
npm run dev
```

Сервер запустится на портах: http://localhost:3000 (HTTP) и ws://localhost:3000 (WebSockets).

```bash
# В новом терминале перейдите в папку фронтенда
cd frontend

# Установите зависимости
npm install

# Запустите проект
npm run dev
```

Интерфейс откроется по адресу: http://localhost:5173.
